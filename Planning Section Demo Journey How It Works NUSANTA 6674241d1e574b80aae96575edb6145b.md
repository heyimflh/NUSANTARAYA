## 3. Fungsi Utama Section

Section ini berfungsi untuk menjelaskan **alur penggunaan NUSANTARAYA** dalam satu perjalanan yang mudah dipahami.

### 3.1 Fungsi untuk user

User akan memahami:

- mulai dari mana,
- fitur mana yang dipakai dulu,
- bagaimana fitur saling terhubung,
- apa hasil akhir dari eksplorasi,
- kenapa pengalaman NUSANTARAYA terasa seperti perjalanan digital.

### 3.2 Fungsi untuk juri lomba

Juri akan melihat:

- produk punya flow jelas,
- fitur tidak berdiri sendiri-sendiri,
- demo path mudah diikuti,
- website terasa matang,
- NUSANTARAYA bukan hanya tampilan visual, tapi punya user journey.

### 3.3 Fungsi untuk homepage

Section ini menjadi jembatan menuju **Final CTA**.

Setelah user melihat alur penggunaan, user akan lebih siap untuk menekan CTA seperti:

```
Mulai Jelajah
Buka Nusa Map
Coba Rute Demo
```

## 12. Interaction Design

## 12.1 Default state

- Step aktif default: **01 Buka Nusa Map**.
- Preview panel menampilkan Nusa Map mockup.
- Step lain terlihat soft.

## 12.2 Hover / click step

Saat user hover/click step:

1. Active step berubah.
2. Preview panel berubah.
3. Step active mendapat border/glow.
4. Icon step active menyala.
5. Preview panel fade/slide transition.

### Desktop

- Hover bisa langsung mengganti preview.
- Click mengunci active state.

### Mobile

- Tap membuka/expand detail step.
- Preview mockup bisa tampil di bawah step terkait.
- Jangan bergantung pada hover.

---

## 12.3 Auto-play optional

Agar section terasa hidup:

- Active step bisa auto-advance setiap 3–4 detik.
- Pause saat user hover/interaksi.
- Matikan auto-play jika `prefers-reduced-motion`.

### Catatan

Auto-play opsional. Jangan wajib, karena bisa mengganggu jika terlalu cepat.

---

## 12.4 Motion

### Section reveal

- header fade-up,
- step list stagger,
- preview panel scale/fade,
- CTA reveal.

### Preview transition

- fade out old preview,
- slide/fade in new preview,
- floating elements animate subtly.

### Connector line

- garis vertikal/horizontal digambar saat scroll,
- dot active menyala.

## 20.3 Spesifikasi Motion Detail

Gunakan Framer Motion. Semua animasi hanya `opacity` dan `transform`.

| Elemen | Dari → Ke | Duration | Delay |
| --- | --- | --- | --- |
| Header (eyebrow/heading/sub) | opacity 0, y 24 → 0 | base | stagger 60ms |
| Step item (masuk) | opacity 0, y 16 → 0 | base | stagger 70ms |
| Preview panel (ganti step) | opacity 0, scale 0.98 → 1 | base | 0 |
| Active glow step | opacity 0 → 1 | fast | 0 |
| Connector line | scaleY/scaleX 0 → 1 | slow | saat scroll masuk |
| CTA penutup | opacity 0, y 24 → 0 | base | 200ms |

<aside>
⚠️

Jika `prefers-reduced-motion: reduce`, semua transform dinonaktifkan; hanya sisakan crossfade `opacity` ≤ 120ms dan matikan auto-play.

</aside>

## 20.4 Desain State Lengkap

Selain default/hover/active, lengkapi state edge-case agar tidak ada tampilan kosong/rusak.

| State | Trigger | Perilaku visual |
| --- | --- | --- |
| Default | Section load | Step 01 aktif, preview map tampil |
| Hover (desktop) | Pointer di step | Lift halus + preview ikut ganti (belum lock) |
| Active / selected | Click / tap / keyboard | Border+glow, nomor emas, `aria-pressed=true`, preview lock |
| Focus-visible | Navigasi keyboard | Focus ring 2px, kontras cukup, tidak hilang saat hover |
| Reduced motion | OS preference | Tanpa transform, tanpa auto-play |
| No-JS / SSR fallback | JS belum hydrate | Semua 7 step + preview tampil statis (stacked), tetap terbaca |
| Asset gagal (icon/avatar) | SVG/gambar error | Fallback ke icon library / inisial, layout tidak bergeser |
