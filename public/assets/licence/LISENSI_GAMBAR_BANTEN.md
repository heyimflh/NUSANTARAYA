## Catatan Penting

1. **Semua gambar bersumber dari Wikimedia Commons**, sebuah repositori media bebas lisensi (Creative Commons / Public Domain). Namun **lisensi persis berbeda-beda per file** — selalu buka halaman "File information" pada tiap link sumber di atas untuk memverifikasi jenis lisensi (CC BY, CC BY-SA, CC0, atau Public Domain) sebelum penggunaan komersial.
2. Untuk lisensi **CC BY** dan **CC BY-SA**, atribusi nama pembuat/fotografer **wajib** dicantumkan, meskipun untuk keperluan internal (bukan halaman publik) atribusi umumnya tidak wajib namun tetap disarankan sebagai etika penggunaan.
3. File-file ini diunduh dalam format asli (JPG) dan perlu dikonversi ke `.webp` secara manual menggunakan tool seperti `cwebp` atau ImageMagick:
	```bash
	cwebp -q 85 nama_file.jpg -o nama_file.webp
	```
4. Dokumen ini dibuat pada 11 Juli 2026 sebagai bagian dari proses kurasi aset visual halaman Nusa Map — Provinsi Banten.
