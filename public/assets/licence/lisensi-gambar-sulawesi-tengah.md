## Catatan Umum
- Semua gambar diambil dari halaman **File:** resmi di Wikimedia Commons — klik tombol "Original file" / "Unduh" pada tiap halaman sumber untuk mendapatkan file resolusi asli.
- Mayoritas berlisensi **CC BY-SA** atau **CC BY**, bukan CC0/Public Domain — sehingga tetap **wajib mencantumkan atribusi** (nama pembuat + tautan lisensi + tautan sumber) saat digunakan.
- Konversi ke format `.webp` perlu dilakukan secara manual menggunakan alat seperti squoosh.app atau `cwebp` (tidak disertakan dalam file ini).
