Layout terbaik untuk section ini adalah **bento grid premium**: satu card besar untuk fitur unggulan, lalu card-card modular untuk fitur lain.

### Kenapa bento grid?

Karena:

- terasa modern dan product-like,
- cocok untuk web app,
- tidak monoton,
- bisa menampilkan mockup UI,
- cocok dengan gaya Google Arts & Culture dan product showcase modern,
- tetap bisa diberi sentuhan heritage melalui pattern dan warna.

Artinya implementasi section tidak lagi perlu bergantung pada placeholder. Planning harus dinaikkan dari **Premium Lightweight** menjadi **Premium Asset-Driven Showcase**.

### Implikasi ke desain

Karena aset premium sudah tersedia, section bisa dibuat lebih kaya secara visual:

- icon final dipakai di semua feature card,
- preview/mockup image dipakai sebagai visual utama card,
- pattern batik/tenun dipakai sebagai texture background,
- RANI asset dipakai untuk memberi karakter pada AI Guide,
- visual bento bisa lebih editorial, cinematic, dan polished,
- card tidak perlu hanya mengandalkan CSS mockup.

### Prinsip penggunaan aset

Walaupun aset sudah lengkap, tetap gunakan secara selektif:

1. **Jangan menampilkan semua aset dalam ukuran besar sekaligus.**
2. **Featured Route Planner harus tetap menjadi pusat perhatian.**
3. **Aset lain menjadi pendukung visual dalam card kecil.**
4. **Pattern budaya cukup opacity rendah.**
5. **RANI boleh lebih ekspresif, tapi jangan mengalahkan hierarchy Route Planner.**
6. **Setiap gambar harus dikompresi dan lazy-load.**

### Cara pemakaian path di Next.js

Karena aset berada di folder `public`, path import di UI memakai root public:

```tsx
<img src="/assets/features/route-planner-preview.webp" alt="Preview Nusa Route Planner" />
<img src="/assets/rani/rani-avatar.webp" alt="Avatar RANI AI Guide" />
```

Untuk icon:

```tsx
<img src="/assets/ui/icons/icon-map.svg" alt="" aria-hidden="true" />
```

Jika ingin icon mengikuti warna card, lebih baik import sebagai React component/SVG inline atau gunakan SVG dengan `currentColor`.

## 11.7 Premium Asset Treatment

Agar aset premium benar-benar terasa mahal, gunakan treatment berikut:

### Image treatment

- Gunakan gambar dalam frame device/card mockup.
- Tambahkan border `1px` dengan opacity rendah.
- Tambahkan shadow lembut, bukan shadow berat.
- Pakai radius besar `24–32px`.
- Beri overlay gradient tipis agar teks tetap terbaca.
- Gunakan `object-cover` dan crop yang rapi.
- Hindari stretch image.

### Icon treatment

- Letakkan icon di dalam badge kecil.
- Badge memakai background sesuai warna fitur dengan opacity `8–12%`.
- Icon memakai warna aksen fitur.
- Tambahkan glow halus saat hover.
- Jangan membuat icon terlalu besar di card kecil.

### Pattern treatment

- Pattern batik/tenun sebagai background layer opacity `3–8%`.
- Jangan menaruh pattern tajam di belakang teks panjang.
- Bisa dipakai lebih jelas di empty area card.
- Tambahkan mask gradient agar pattern fade natural.

### RANI treatment

- `rani-avatar.webp` dipakai di chat header/avatar kecil.
- `rani-sapa.png` dipakai sebagai ilustrasi besar jika card RANI mendapat ruang cukup.
- `rani-typing.json` dipakai hanya pada micro mockup chat, bukan animasi besar.
- Jika animasi terasa berat, fallback ke CSS typing dots.
